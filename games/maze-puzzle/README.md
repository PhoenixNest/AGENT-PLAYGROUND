## 🚀 Quick Summary of Project Direction

- **Core Gameplay Foundation:** Satisfying 3D rotational physics maze where players guide physical objects through multiplier checkpoints and funnel them into a target destination.
- **Thematic Overhaul:**
  - Balls $\rightarrow$ **Orbital Space Debris / Satellite Scrap**.
  - Maze $\rightarrow$ **Orbital Ring Debris Chutes / Salvage Station Centrifuges**.
  - Collection Cup $\rightarrow$ **Artificial Micro-Black Hole Event Horizon Unit**.
  - Daily Missions $\rightarrow$ **Orbital Sector Cleaning Contracts (Daily Shift)**.
  - Reward Economy $\rightarrow$ **Scrap Credits / In-Game Salvage Tokens** (strictly non-monetized; earned solely via skill and clearance volume).
- **Apple App Store Guideline 4.3 Compliance:** A complete divergence from generic hypercasual tropes by adding rich sci-fi lore, physics variations (gravity pulses, microgravity drift), distinct hazard elements, non-linear progression, and zero invasive ads or predatory paywalls.
