# Latin-script layout audit — 2026-10-12

Verifier pass on the nine Latin tables now in `integration/i18n`: `de`, `fr`, `es`, `it`, `pt-PT`, `vi`, `fil`, `id`, `uz`. Tables, specs, and render code were left as they are. Editor stills only (Unity 6000.4.0f1, macOS). No device, no native-speaker review.

`LocLanguageAuditTests` loads each real table from Resources, sets the language, and runs `LocOverflowAudit` over all 90 spec files (`*__zero.json` and `*__iphone.json`). Hard findings fail the test. Hard here is outside, overlap, band, wrapped-in-control, missing-glyph, and wider. `LocLanguageStillTests` paints the 90 stills plus one extra language-picker still with the check moved onto the active language. Teardown sets the language back to `en`. English paint matches a paint taken before the language was activated, and it matches again after teardown.

Machine reports: `/tmp/maze-i18n/audit-all/<code>/overflow.txt`. Stills: `/tmp/maze-i18n/audit-all/<code>/stills/`. Picker record: `/tmp/maze-i18n/audit-all/<code>/picker-marker.txt`.

The earlier German-only report (`de-audit-2026-10-12.md`) describes an older `de` table. This pass uses the current tables. The daily pill is now `0 / 3 FERTIG`, the defeat button is `Nochmal`, and the earned badge is `✓ FREI`.

## Uzbek (`uz`)

1. Dock `SHOP` → `doʻkon`, drawn `DOʻKON`, control-ellipsizes to `DOʻK…` (4). The modifier is inside the cut-off label.
2. U+02BB (`ʻ`) is a modifier, and it draws as a detached high apostrophe with gaps on both sides. `OʻYNA` reads as `O ' YNA`, `sovgʻa` as `sovg ' a`, `choʻntak` as `cho ' ntak`. The same mark is visible in `OʻYINCHOQ`, `gʻ`, `YANA OʻYNA`, `OʻYIN HISSI`, `YIGʻILGAN`, and `BOʻSHLIQDA`. It is a raised apostrophe, and it does not sit tight against the letter.
