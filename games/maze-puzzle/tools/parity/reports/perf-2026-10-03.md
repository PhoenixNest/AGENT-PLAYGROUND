## D3D11 opt-in

The parity capture player (tools/parity/unity/build.ps1, ParityBuild) does not set a graphics API, so Unity 6 keeps the default (D3D12 on this machine) and stills stay on that path. A separate player for play mode is tools/parity/unity/build-play.ps1 (PlayBuild), which forces Direct3D11 only for that build and writes Builds/Play/OrbitalSalvage.exe. It restores ProjectSettings afterwards, including the original graphics API list.

Editor Play mode uses the graphics API of the Editor process. Start the Editor with -force-d3d11 to play on D3D11. The running API is SystemInfo.graphicsDeviceType. Menu item: Orbital Salvage/Build Play Player (D3D11).

## Findings

`UseLayerCache` was hardcoded false because `Graphics.Blit` replaced the frame. Settled animated draws now source-over cached static layers (`cache yes`). On a GPU that stayed at 76–86%, home Draw median is 3.51 ms (D3D12) and 3.07 ms (D3D11); every run is under 8 ms average and 12 ms p95. Stage time on the 3.50 ms draw: elements 106 (was 142), draw calls 325 (was 384), vertices 129k (was 172k), blit 0.003 ms, 0 ReadPixels during the timed loop.

The layer readback moves 1.57% of animated-home pixels by at most 2 levels. Strict scores against the web offset frames stay 96.75 / 0.9736, 96.70 / 0.9729, 96.72 / 0.9729. The settled `home_default` still is byte-identical, and the 13 stills keep their previous scores. `-parity-no-layer-cache` turns the cache off.

Live frame time is the GPU fence (D3D12 ~13.5 ms, D3D11 ~5.6 ms) plus ~5.5 ms CPU. Caching the sky gradient does not move that. Scale 0.5 is still slower (18.5 ms vs 19.7 ms on the same D3D12 run), so the default stays 1.0. Stars pulse with time, so the starfield is not a static bitmap. One D3D11 live run started at 0% GPU and then spiked (nofence 7.83, fence 17.84, which is the 25.67 / 101.96 max). The other four match the baseline. Median D3D11 live is 11.43 ms average, p95 17.41 ms, still above the 16.7 ms p95 target. nvidia-smi stayed above 15% for almost every wait (LM Studio and Cursor on the GPU).
