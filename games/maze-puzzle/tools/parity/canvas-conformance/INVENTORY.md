| linear | 415, 504 |

Stops: 3-stop linear sky (hex6 stops, lines 415-418), funnel linear gradient with hex8 + `rgba(56,189,248,0.04)` stops (504-507), radial halo with hex8 stops ending in `rgba(0,0,0,0)` (591-594; transparent-black end stop makes premultiplied vs straight interpolation visible), bumper dome radial (928-). Radial gradients all have `r0 < r1`; the dome one has an off-centre inner circle (`x0 != x1`).

## Transforms

- `setTransform(dpr,0,0,dpr,0,0)` per frame (320).
- `translate` + `rotate` + uniform `scale` nesting (`save`/`restore` depth <= 4).
- One shear: `transform(1, 0, -0.22, 1, 0, 0)` (1698), booster gate; subsequent fills and strokes (round rects, text) are drawn under the shear.
- Non-uniform scale is never used.

## Text (see SPEC Appendix B for the per-site table)

Fonts: `bold 13px Fredoka`, `11px Nunito`, `bold 10px Fredoka`, `900 10.5px Fredoka`, `bold 9.5px Fredoka`, `900 16px Fredoka` (all with `, sans-serif`). `textAlign = center` everywhere; `textBaseline = middle` in 5 sites, default `alphabetic` for floating text. One `strokeText` (floating text outline, `lineWidth` set by the caller, round joins are not requested so miter applies).
